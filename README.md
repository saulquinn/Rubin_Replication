# Rubin_Replication
This repo contains all files relating to a 2026 study replicating the work done in a 2025 study by Choi et al. (https://arxiv.org/abs/2507.01343).

The Python code used for this project can all be found in the following Colab notebook:
https://colab.research.google.com/drive/1iN1CKLFwzxi5_Tojs3xmoSqE7LWfY60J?usp=sharing

The files stored in this repo are required to run the above code.  However, it is simpler to make a copy of the following Google Drive folder to save in your Drive to run the code:
https://drive.google.com/drive/folders/1WBxnwVGEf2KLLrfX3GyZAj3VT7vUeOGx?usp=sharing
